# Voz Amiga - Tecnologia Assistiva 🍎💧🚨

## 📋 Sobre o Projeto
Este é um projeto de extensão desenvolvido para o curso de **CST em Análise e Desenvolvimento de Sistemas**. O objetivo é fornecer uma ferramenta de **Comunicação Aumentativa e Alternativa (CAA)** para pessoas com limitações severas de fala ou locomoção.

O aplicativo permite que o usuário expresse necessidades básicas (fome, sede, dor, etc.) através de botões intuitivos que utilizam síntese de voz nativa do navegador e enviam alertas em tempo real para um banco de dados monitorado por cuidadores.

## 🚀 Tecnologias Utilizadas
* **Vite + TypeScript**: Para uma interface rápida, tipada e moderna.
* **Supabase**: Backend-as-a-Service para armazenamento de logs de alertas em tempo real.
* **Web Speech API**: Para a conversão de texto em fala (Text-to-Speech).
* **CSS3 (Flexbox/Grid)**: Interface focada em acessibilidade e alto contraste.

## 🎯 Objetivos de Desenvolvimento Sustentável (ODS)
Este projeto está alinhado com as seguintes metas da ONU:
* **ODS 3 (Saúde e Bem-Estar)**: Melhoria na comunicação de pacientes e assistência à saúde.
* **ODS 10 (Redução das Desigualdades)**: Inclusão social de pessoas com deficiência através da tecnologia.

## 🛠️ Como Executar o Projeto
1.  Clone o repositório:
    ```bash
    git clone [https://github.com/seu-usuario/projeto-extensao-acessibilidade.git](https://github.com/seu-usuario/projeto-extensao-acessibilidade.git)
    ```
2.  Instale as dependências:
    ```bash
    npm install
    ```
3.  Configure suas variáveis de ambiente no arquivo `.env` (URL e Key do Supabase).
4.  Inicie o servidor de desenvolvimento:
    ```bash
    npm run dev
    ```
